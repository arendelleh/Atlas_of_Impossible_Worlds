# Scene previews

Upload actual screenshots of the running application to this folder.

## Upload on GitHub

1. Open `assets/previews` in the repository on the `main` branch.
2. Select **Add file → Upload files**.
3. Drag in PNG or JPG images. Suggested names are listed below.
4. Select **Commit changes** to save the images to `main`.
5. Edit the root README and replace its upload instructions under Preview with the Markdown below, including only images you have actually uploaded.

| Image | Suggested filename |
| --- | --- |
| Central observatory | `observatory.png` |
| Garden of Unborn Stars | `garden.png` |
| Factory of Forgotten Sunsets | `factory.png` |
| Library of Unwritten Universes | `library.png` |
| Kingdom Between Seconds | `kingdom.png` |

## Markdown for the root README

```markdown
### Central Observatory
![Central observatory](assets/previews/observatory.png)

### Garden of Unborn Stars
![Garden of Unborn Stars](assets/previews/garden.png)

### Factory of Forgotten Sunsets
![Factory of Forgotten Sunsets](assets/previews/factory.png)

### Library of Unwritten Universes
![Library of Unwritten Universes](assets/previews/library.png)

### Kingdom Between Seconds
![Kingdom Between Seconds](assets/previews/kingdom.png)
```

Filenames are case-sensitive on GitHub. If your file is JPG, use `.jpg` in its Markdown path. The application's P key saves TGA files; convert those to PNG with an image editor before uploading. Add real application captures rather than generated mockups.
